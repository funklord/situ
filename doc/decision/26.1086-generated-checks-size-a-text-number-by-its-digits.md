# 26.1086: generated checks size a text number by its digits

Status: recorded
Date: 2026-11-18
Source: the full gate on 0070's first stack, `make test-c`

**`gen-checks` placed the member after a counted text number six bytes too
far.** `check_counted_digits_places_its_members_in_one_instance` gives each
variable member two elements and computes where the next member starts
from each element's size -- and took a text number's element as its
VALUE's width, so `decimal u32 count[n]` was eight bytes for two digits and
`rest` was expected at 9 where it sits at 3. The accessors were right; the
check was wrong, and failed `make test-c` on the first counted text number
in the corpus, `edges.counted_digits` (26.1078).

## The rule

A text number's elements are its digits, one byte each.
