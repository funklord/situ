# 26.926: a run a terminator ends has one

Status: recorded
Date: 2026-11-07
Source: RFC 8949's vectors with their last byte cut, and a verdict by hand

**All six readers passed a message with no terminator.** With `leaf { u8 k; }`,

    struct last { leaf es[] until "\xff"; }

`01 02` has no `ff`, and every reader said whole, wherever the run was the last
member. `required` over the same bytes has always said incomplete, so `validate` and
`required` disagreed about one message in all four backends. It surfaced when
`example/cbor` took indefinite items and its test cut each vector by a byte.

Section 8.6.1 says a missing delimiter is an error, and 26.895 made `| end` the way to
say otherwise, but neither reached a run. The comment at C's check read "a run that
ran out of buffer has no elements to be wrong about", and `pack.py`'s, that asking a
run said CONSTRAINT for `kv_block` where C said OK: agreement, recorded as a reason.

**The walk says, and not the last bytes.** An element may end in the terminator's
byte: `01 ff` under `pair es[] until "\xff"` is one element and no terminator. So each
backend has an `_ended`, the run's own walk returning at the terminator, and the
packer writes the `terminated` row for a run, which both walkers answer from their
walk. The check runs before the elements, as a delimited member's does, so a message
that was refused for a short tail or a cut element now says it has no terminator:
five pins moved from BOUNDS to CONSTRAINT, and every one is refused either way.

**A run directly in an arm** had no walk unless something followed the variant.
`_arm_ended_walk` now takes a tail of zero as a request for the terminator alone.

**`example/id3` says `| end`.** Its frames may fill the tag, with no padding to stand
in for one, and the schema's own comment had said so.

**`while` has the same hole and another answer**: 26.927.
