# 26.1170: a rule reads a run's elements

Status: recorded; built in the four backends, declined by both walkers
and the dissector
Date: 2026-11-24
Source: the holder, 2026-11-24 -- "we likely want rules over lists" --
and fuzznet's cases, by its own ranking: its manifest's pairs ascending
by a key of two members (built as 26.985's composite key, 3e4a81b0),
its remote permit's "none stands alone", its group list's "no name
twice".

## The rule

A `when` may ask a run's elements:

| form | value |
|---|---|
| `any(r in s.rules: pred)` | 1 where some element holds `pred` |
| `all(r in s.rules: pred)` | 1 where every element holds it |
| `count(r in s.rules: pred)` | how many do |
| `count(s.rules)` | how many elements there are |

`pred` reads the element's own members, `r.kind`, and bare names --
constants, enum and token members; each element is asked over its own
view. "None stands alone" is
`when any(r in p.rules: r.kind == none) && count(p.rules) > 1 refuse ...`.

**Bounded as `sum` is** (section 10): the run's own elements bound the
walk, and each reader walks it ONCE -- the element measured by its own
extent, the offset carried -- because a reader stepping by index re-walks
a run of variable elements from its start for each, which a hostile
message makes quadratic.

## Refused, each with its reason

- Outside a `when`: a size or a bound is arithmetic over fields, and a
  rule is asked once, in `validate`.
- One rule inside another: pairing two runs' elements is not one pass.
- A body reading the enclosing struct (`r.kind == s.c`): one comparison
  over two views is not built yet.
- A run that is not of structs, or that a terminator ends: the walk
  steps by the element's extent, which a delimited run's terminator
  adds to. A counted run and a `while` run are walked.

## Readers

C, C++, Rust and Python each emit one helper per rule, named for the
`when` and its place in it (`traverse.RunRule.helper`), so the
definition and the call agree; the rule's place in the `when` becomes a
name the renderer supplies, as a byte-run comparison's does (26.1128).
Both walkers decline a struct holding one -- the image has no program for
it -- and the dissector declines the rule, saying so beside its expert.

## `unique`

`unique(r in s.rules: r.name)`: no two elements share the key -- one
member of the element, a number or a run of bytes, compared byte for
byte and length for length. The group list's "no name twice" is
`when !unique(g in l.groups: g.name) refuse ...`.

Every pair is compared, so the run must be BOUNDED: its largest size
over its smallest element is at most 4096 elements
(`traverse.UNIQUE_MOST`, about eight million comparisons at worst), or
`unique` is refused with that number -- a run with no largest size is a
count of comparisons the message chooses. C, C++ and Rust compare each
element with every one after it; Python keeps what it has seen.
