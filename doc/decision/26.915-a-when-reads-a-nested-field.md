# 26.915: a `when` reads a nested field

Status: recorded
Date: 2026-11-06
Source: trying cpio's sum, under the lens 26.912 left

A size could say `h.len`; a `when` could not, so a rule relating a nested header
to its body had no spelling. Only the refusal stood in the way: all four backends
and both walkers resolve the path once asked.

**Relaxing it was the mistake to avoid.** Checking the first step alone let a
path through a `u8` build and read nothing, and gave back the `UnknownName`
tracebacks 26.439 refused this check to end. `_step_through` walks the path: each
step exists, and each before the last is one nested struct, always there. A run
has no one element to name, and an arm may not exist.

The first test of this found 26.916.

**cpio's `newc_crc` sum stays unstated.** `when` can now reach `header.check`,
but `sum` is only read by a size (26.896), and asking it of a run of bytes in a
`when` is a separate feature.
