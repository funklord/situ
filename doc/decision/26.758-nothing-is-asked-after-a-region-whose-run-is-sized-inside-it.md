# 26.758: Nothing is asked after a region whose run is sized inside it

Status: recorded -- fixed; closes the item 26.752 left open
Date: 2026-10-30
Source: `project.md` section 26

    sealed body(sealing_aead) { u8 n; u16 vals[n]; }
    tag u8 mac[16] covers(body);
    u8 after;

`n` is inside the region, so from the plain view it is ciphertext, and the
arithmetic that places `mac` has nothing to read (26.440). All four
backends decline `mac` and `after`, consistently. The differ did not: its
stop after a region asked `_region_walks`, which knew a walked interior
(`unmeasurable_inside`) and a self-delimiting one (26.570) and not a
length that NAMES an interior field. So the `TAG` probe and the scalar
probe after it named accessors nobody emits, and the C driver did not
compile -- a schema with this shape was compared by nobody. The same gap
asked a plain `coded` region with a closed-form codec for its bytes.

`_region_walks` now also stops where an interior member's `sized_by` or
`size_expr` names a member of the same region. Over this shape, a
`[n + 1]` spelling of it and a `coded` region over `doubling`, the four
drivers build and agree; with the fix reverted C does not build
(`test_a_tag_after_a_run_sized_inside_its_region.py`).

## C's note was false

C declined `mac` with the codec sentence: "codec `sealing_aead` has no
closed-form expansion ... a `length_preserving` codec ... keeps the members
after it addressable" -- of a codec declared `length_preserving`. The
blocker is the region, and the note's last branch assumed a region blocks
only through its codec. A region whose codec IS closed form now says its
length is read from its own interior, which from outside is the codec's
output, and that a length field before the region is the remedy.

## A lens that found nothing

26.757's shape -- a consumed terminator the framing cursor is not moved
past -- was probed across 25 terminated-member forms (byte runs, `|`
alternatives, `escape`, `quoted`, `trim`, delimited and run text numbers,
runs of fixed and variable records, nested lists, a run in a run, a run
before a peeked variant). All four backends framed every message at its
exact length.
