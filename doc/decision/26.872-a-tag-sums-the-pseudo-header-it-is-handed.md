# 26.872: A tag sums the pseudo-header it is handed

Status: recorded -- 232 builders over 33 schemas, 98 of them an arm
Date: 2026-11-05
Source: 26.867, which left this declined

`prefix(...)` names bytes a tag's codec sums and the message does not hold, so
the three builders take them as a parameter beside the tag's own place, as C
does: `<tag>_prefix`, and its length in C++. The reader's `_compute` and `_check`
refuse the wrong length, so nothing here restates it. `example/tcp` and
`example/udp` now build.

`test_a_nested_member_is_one_whole_message.py` holds all four to a sum written
from RFC 1071 rather than from the codec, and to refusing a short pseudo-header.
