# 26.870: The builders write a text number

Status: recorded -- 230 builders over 33 schemas, 98 of them an arm. Argued
spans, wide runs and pads are what is left
Date: 2026-11-05
Source: 26.869's measure, and hull's tar header (section 19 of its suggestions)

`decimal`, `hex` and `octal` members are written as C writes them, through a
`_digits` beside each language's `_store`, so a size field reaches it as a
caller's scalar does. The fixed form pads with zeros and refuses a value wider
than its digits. The minimal form counts the width first, then writes the byte
that ends it, and a negative value's sign is a byte more. Rust's and Python's
runtimes gain `format_uint` and `format_int`, line for line with C's.

A text number's value is bounded by its scalar and not its width: the size
limit in `_size` read `size_bits`, which here is the digits.

`test_a_nested_member_is_one_whole_message.py` holds all four to the bytes:
leading zeros, upper-case hex, octal, a size field in digits, too many digits,
minimal, and a negative number.
