# 26.992: hull's agent protocol under verify

Status: recorded
Date: 2026-11-13
Source: hull, `.git/cc-inbox/20261113T0639Z` -- `situc verify` failed on 4
of 37 vectors of `agent/protocol.situ` from situ 1cae66fc on, bisected
there with `git bisect run`; hull held its pin at 6f807f01

1cae66fc made `validate` measure the arm a variant selects, and that
reached two faults that had waited for a caller.

**A class named like a local.** The generated Python binds locals --
`start`, `size`, `data`, `value`, `view` and some forty more -- and Python
makes a name local to the whole function if it is assigned anywhere in
it. hull has a struct named `start`; the property measuring its arm said
`start = 1` and then called `start(...)`: "'int' object is not
callable". A new final pass over the module asks `ast` which names each
function binds and, where one is a struct or enum class, calls the class
through `_situ_<name>`, appended at the end of the module. Decision
0025's move, as `_unshadow` makes it for a builtin: the reference is
renamed, never the name the schema chose. C names a type with its prefix
and Rust in `PascalCase`, so neither meets it.

**A walk that asked itself.** The one-pass walk (26.918) finds the fields
a length reads, each from a cursor. A variant's arms were measured through
their own extents, and an arm's extent derives its start -- which, past a
first variant, reads that variant's discriminant, which is found by the
walk. hull's `exec` has two such variants and a read after both: Python
recursed to its limit, and the same shape overflowed the stack in C, C++
and Rust, on a well-formed message. Each walk now measures a variant from
its cursor, every arm through its `_from(at)`, which exists wherever a
walk is emitted.

`test_python_names_a_class_like_its_locals` is both shapes cut down from
hull's: `verify` over five vectors, all four backends and both walkers on
each. It fails with the change reverted, C, C++ and Rust by crashing. The
corpus's generated code is byte-identical in all four targets before and
after -- no committed schema had either shape -- and hull's 37 vectors
conform.
