# 26.1001: a builder writes COBS

Status: recorded
Date: 2026-11-13
Source: 26.998, which left COBS out until its encoder was read, and
26.1000, which found its bound short

With COBS's bound corrected to `+ 2` (26.1000), the builders write a COBS
region as they write SLIP: the caller hands over the content and the
generated encoder, which writes its own zero delimiter and keeps every other
zero out of the body, encodes it. The region must end at that zero.

**The room formula changes for every code**, from `ceil(len / per) *
worst` to `ceil(len * worst / per)`, plus the constant and any delimiter
the encoder does not write. Both bound every length for the three codes
26.998 admitted; the first is wasteful at a large `per` -- one byte of COBS
content demanded 257 -- where the second asks `len + ceil(len / 254) + 2`.

**And a Rust builder file imports `situ_rt`'s `self` only where it names
`situ_rt::`.** A builder of nothing but a coded region calls the module's
own kernel, so slip's and smtp's builders from 26.998 would not compile
under `-D warnings`: an unused import. `test_the_four_builders_agree`
compiles with `-A warnings` and the Rust lint sweep does not build the
builders, so neither could see it; it was found compiling COBS's builder
by hand, and `test_the_rust_builder_compiles_with_warnings_denied` now
builds slip's that way, failing with the fix reverted.

**Measured.** Python, against the published examples (`00` to
`01 01 00`, `11 22 00 33` to `03 11 22 02 33 00`, 254 non-zero bytes to
`FF` and the run and `00`), decoded back through the reader. Rust, under
`-D warnings`, and C++, under `-Wall -Wextra -Werror` with the C codec,
were built by hand on the same schema and wrote the same frames; no corpus
schema has a COBS region, so the four-way comparison does not reach it.
