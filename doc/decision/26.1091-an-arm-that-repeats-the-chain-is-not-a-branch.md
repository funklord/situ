# 26.1091: an arm that answers what the chain already does is not a branch

Status: recorded
Date: 2026-11-18
Source: the cppcheck lens 26.1074 opened over the corpus

**970 of the corpus's cppcheck findings were one shape.** A variant's
length and an alignment are each a ternary chain over the discriminant,
one comparison per arm, the last falling back to the default -- and an arm
whose length equals what the chain already answers produced
`(kind == 0u ? 0u : 0u)`: a branch whose two values agree, which cppcheck
names `duplicateValueTernary`. Correct, and noise in every consumer that
runs an analyser over generated C or C++.

## The rule

An arm whose value is the chain's own is not added to it, in C's and C++'s
variant length and alignment. The value of the chain is unchanged for every
discriminant.

## Measured

The corpus, 63 schemas through cppcheck's warning and style checks:
`duplicateValueTernary` 970 to none, every other class unchanged. The C and
C++ codegen suites, the four-way and framing comparisons and `required`
over the corpus pass.
