# 26.858: Rung 2 writes in all four, and the four write one message

Status: recorded -- C++ and Rust serve Python's class; widening the class
is open. C's builder still reaches far further
Date: 2026-11-04
Source: 26.854 and 26.855, which left C++ and Rust as what remained

`--layer edit` now emits `<schema>_build.hpp` in C++ and
`<schema>_build.rs` in Rust, for the class 26.855 chose: a struct whose
every member is a whole-byte fixed scalar. `situc/codegen/plain_build.py`
states the class once, for the three languages. Each one takes the
sequence C settled in 26.610: bounds-check, store, advance, then validate
through the ordinary view over exactly what was written.

26.854's notice is gone, because the absence it named is gone. A struct
outside the class is still named on stderr, so the boundary is a struct's
refusal now rather than a language's absence.

## A member is taken as its integer, not its enum

An `enum class` or a Rust enum can hold only what it names, and `default
= pass` says a message may carry a value nothing names. Python's builder
takes an int for the same reason.

## The instrument: four builders, one message

A round trip through one backend's own accessors cannot see a fault its
reader and writer share. `test_the_four_builders_agree.py` builds every
served struct in all four languages from the same values and compares the
bytes, and a refusal has to be one all four make. It found two faults on
its first runs, neither in the new emitters:

- **C wrote `native` big-endian** (26.857). Three languages agreed against
  the oldest one.
- **The class over-claimed.** `u8 data[(hdr_ext_len + 1) * 8 - 2]` has no
  `sized_by` and no `array_count`, and its `size_bits` is its minimum, so
  it passed for a six-byte scalar, and 26.855's Python builder took an
  integer for a variable run. C's signature took a pointer there, which is
  what showed it. `is_plain` now asks `is_fixed_size`. The class is 29
  structs over 15 schemas, not 26.855's 45.

## Tests

`test_the_four_builders_agree.py` over the corpus: 15 schemas compared, the
rest having nothing in the class. `test_rung_two_reaches_every_target.py`
replaces 26.854's gate: all four emit a builder for `modbus`, and a struct
outside the class is named for the three. With `_writer` swapped for the
wrong order in Rust alone, the differential fails.
