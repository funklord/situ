# 26.884: a real PES packet, and two faults it found in the checks

Status: recorded
Date: 2026-11-05
Source: the fan-out run, 26.881

26.881 had met one real format, mqtt. `example/pes` is the second: six
flag-gated groups, which a builder per combination would have made 96
builders. It is one, with 13 arm constructors, and the six flags are computed
from the arms. Five vectors are ffmpeg's packets, one is laid out by hand and
read back by tshark, and all six rebuild byte for byte.

## What the schema could not say

- **The extension group.** Its size hangs on flags of its own, and `size()` in
  a length is a compile-time answer that cannot name a variant. It stays
  unparsed in `rest`, with the stuffing and the payload.
- **The stuffing length.** Flag arithmetic reads it, but a length over several
  fields has no builder (26.630: one field, positive scale), and that boundary
  is deliberate. So `header_data_length` is the caller's number and nothing
  checks it against the groups.
- **`u24`** has no builder, so the start code is `u16` and `u8`.

A run-time `size()` of a variant would close the first two. It is new language
in four backends and two walkers, and PES is the one consumer so far.

## Two faults in `gen-checks`

**A pin behind a variant was written to byte 0.** A member of a nested struct
in an arm after another variant carries `offset_bits` measured from that
struct. Python, C++ and Rust read it as a place in the message, and their
checks failed on `pes.start_high`. `measured_from_a_moving_base` names the
condition, which one C check had spelled out, and every check that writes a
raw byte now asks it. The corpus held no such member: generated C, C++ and
Rust checks are unchanged on all of it.

**Two arms pinning one name shared a Python test.** Python named a check
`struct_member` where the others use the whole path, so the second `def`
replaced the first in silence. Nine of modbus's checks had never run. They run
now and pass. 13 schemas' Python suites change: their test names, and in mqtt,
id3 and json the wording of a decline. No test changes what it checks but
modbus's nine.

## Tests

`test_a_real_pes_packet_is_one_builder_call.py` and
`test_a_check_breaks_the_member_it_names.py`. Making the predicate false turns
the first check red, and the old name turns the second red.
