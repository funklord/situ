# 26.861: The builders write a variant, one arm at a time

Status: recorded -- 104 builders over 26 schemas, 32 of them an arm. Nested
members since, and a tag that is not a whole scalar is refused (26.862)
Date: 2026-11-04
Source: 26.860's measure, where variants were the largest slice left

A struct holding a variant gets one builder per arm, as C has: which arm
is said by which builder you call, so the discriminant is the builder's
to write and cannot disagree with the body. `plain_build.units` is the list
of builders, a struct or one arm of it. `build_<struct>_<arm>` in Rust and
Python, `<class>_<arm>` in `situ_build` in C++.

Two roles arrive with it. `armtag` writes the arm's own case value, and
`peeked` writes nothing, its bytes belonging to what follows. The default
arm's value is the caller's, and one a named arm claims is refused, since
it would make the message read as that arm.

An arm this class cannot write is named by itself on stderr, so
`request.read_coils` is declined while its siblings are built.

**A scalar part is one value or it is not served.** A pad or a run in an
arm reaches the plan as a scalar part with a width that is not its
scalar's: Python raised `OverflowError` on `padded_arm`'s pad, the first
time an arm was run. `_serves` compares the two.
