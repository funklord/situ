# 26.1032: the other three write packed decimal

Status: recorded
Date: 2026-11-14
Source: 26.1029, which was C's alone

**26.1029 let C write packed decimal** -- an RTC's time registers -- and
the other three refused it. Each of their runtimes already has the encoder
its reader's setter uses (`bcd_encode` in Python and Rust; C++ shares C's
`situ_bcd_encode`), so each builder now writes a plain BCD member, packed
or a whole byte, through it, refused past what the field holds exactly as
C refuses it.

**Measured**: the agreement test builds the DS1307's `wall_clock`, and the
`rtc_frame` that holds it, alike in all four, read whole by the reader and
the walker; and Python writes 2026-11-14 02:59:30 Saturday as C does, `30
59 02 07 14 11 26`, refusing seconds of 80.
