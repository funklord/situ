# 26.1075: a token set may end where its length says

Status: recorded
Date: 2026-11-18
Source: 0070's first measurement -- fuzznet's FLAG cell written as a struct

**A token set could only end at a delimiter.** `flag_word word[remaining]`
was refused as "gives a width to a token set", so a value that is the whole
of its frame had no spelling: a settings cell's `on`, a keyword that ends a
datagram, a vocabulary word a length field sizes. The refusal's reason was
that a token set decides no width of its own, which stays true; a length the
message gives says where the member ends as well as a delimiter does, and
the span is compared against the arms the same way.

## The rule

- A token member may be sized -- `[remaining]`, `[n]`, any length
  expression -- as well as delimited. The span is compared whole, so a
  prefix of an arm (`o` of `on`) is no spelling, and an empty span is none.
- A constant width no arm has is refused: nothing could ever match.
- Inside a variant arm it is refused for now. An arm's member is checked
  through a different path in every reader, and none asks a sized token
  there yet; refusing says so where reading it unchecked would not.
- Seven readers: C, C++, Rust and Python check membership in `validate`;
  the packer writes the delimited token's membership row (kind 14) for a
  sized one, so both walkers ask it with no change of their own; the
  dissector already shows a token member as a string whatever sized it.

## Measured

`test_a_token_set_may_end_with_the_frame` asks all six validating readers
over eleven frames, for a `[remaining]` member, an `[n]` one and a fixed
`[2]` one -- the last had no `_len` accessor in C, so C's check names the
width instead, and the header did not compile until it did. Sabotaged:
without the packer's row the C walker answers 0 for `yes` where the four
backends answer 2; without C's check, C answers 0 where the other five
answer 2. `edges.situ` carries both shapes (`flag_cell`, `counted_word`),
so the random-draw sweeps and the dissector differential ask them.
