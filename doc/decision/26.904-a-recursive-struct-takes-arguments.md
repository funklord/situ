# 26.904: A recursive struct takes arguments

Status: recorded
Date: 2026-11-06
Source: 0068 step 5's other half, and IKEv2, where a payload's `next` names the
body of the payload after it

    struct payload [depth = 16] {
        parameter u8 kind [stream];
        u8 next; bit critical; reserved u7; u16 length [min = 4];
        variant body switch (kind) { ... }
        variant rest switch (next) {
            case 0: nothing none;
            default: payload(kind = next) more;
        }
    }

0068 says "a struct naming itself is still refused, as is one that can contain
itself through any chain". That sentence is superseded here: an accepted record
is not edited.

## Decision

A struct in a cycle takes a `parameter`, and a member hands it arguments as a
single nested member, an arm, and a counted, `while` or delimited run. Each
depth-carrying function carries the tail beside the depth: `_extent_at`,
`_nesting_at`, a run's `_span_from_at` and `_fits_at`, and an arm's and a nested
member's `_extent_at`. `_run_count_args` is the one answer to what `_count`
takes, for its definition and for the probe.

## What it took besides the tail

The argument is what made these reachable. Most were there without it.

- **`[depth]` follows the cycle, not the type.** A member of a struct outside the
  cycle entered it at level one, so `tree { node root; }` cut a `node` nested
  exactly `[depth]` deep to nothing and read the next member from inside it, in
  all four. A struct taking an argument is reached in no other way.
  `traverse.descends` says whether a member carries the depth, and one that
  enters a cycle starts it at zero.
- **`[depth]` is asked over the frame where a member enters a cycle.** A view is
  sized by an extent that stops one level past the bound, so a chain ending
  where the view ends hid the level that broke it, and `validate` called a
  message too deep short.
- **C's nested `_view` and Python's plain walks measured from another level than
  the rest**, so past `[depth]` each answered a different number.
- **A `default:` arm had no guard in any nesting probe**, so the last payload of
  a message with bytes after it counted them as a level. C also counted an empty
  view at the frame's end.
- **A value handed to a parameter is held to its range** (`handed_range`).
  `length - 4` is proved by reading `[min = 4]`, and that is a check, so a
  message breaking it reached every reader as -3: C and C++ wrapped it, Rust
  did in a release build and panicked in a debug one, Python and both walkers
  kept it. All of them hold it now, as a negative length reads zero, and
  `validate` refuses the message for the rule it broke. This reaches every
  parent and not only a recursive one. `situ_clamp_i64` is new in the runtime.
- **A `while` run's condition reads the element's field, through the element's
  arguments.** C rendered the element's `arg_b`, which is the parent's name in a
  self-recursive struct: `node(b = n) kids[] while (more != 0)` compiled and read
  the wrong byte. The C walker evaluated it over the parent's binding.
- **Four shapes with no cycle in them failed at `cc`**: a variant switched on a
  parameter at a static offset, a `while` and a delimited run handing on the
  parent's parameter, and a bound on a field behind an argument.
- **The walkers' depth walk, which any `[holds]` turns on, built a child with no
  arguments**, and C's followed a `while` or delimited run as one member and read
  its terminator as a struct.
- **A variant's framing dropped the arm's arguments** in C++, Rust and Python.
- **Python's `except VersionError` around an arm caught the arm's own verdict**,
  so `default: error` in a struct an arm holds read as the arm being absent and
  the message as whole.
- **The dissector carries no depth**, so a member of a cycle is declined. Asked
  anyway `gen-dissector` ran out of stack on an arm that is the recursion, with
  an argument or without, and through a run it named a function nothing defines.

## What stays refused

Each with a sentence naming the shape, and none of them built without an
argument either: a `[remaining]` run of the struct's own cycle, which then has
no extent; a run in an arm of its own cycle, on which C stops at an assertion;
an `indexed` region of its own cycle. A run of a cycle the struct is not part of
is built. `at` and sealed or coded interiors are refused as they were.

## Limits

- Both walkers count the parent as a level. Under a parent outside the cycle a
  message exactly `[depth]` deep is `cannot-say` there and whole to the four, as
  it was for a recursive struct with no argument.
- Past `[depth]` the four say malformed and both walkers `cannot-say`, as they
  did, and a walker refuses a nested view the four cap at the bound. An arm or a run element entering a cycle does not ask `[depth]` over the
  frame, so a chain ending where its view does is short there.
- A delimited byte member behind an argument-sized one does not compile in C.
- A recursive delimited run the frame cuts before its terminator is whole to the
  four and short to both walkers, with or without an argument.

## Rejected

- Wrapping the handed value in Python and both walkers to match C: `required`
  then asks for 65 KB on a four-byte header, and the verdict is short where a
  rule is broken.
- Seeding a plain entry with minus one so `depth + 1` lands on zero, in place of
  `descends`: unsigned in C and a panic in a Rust debug build.
- A second tail through the walkers' 36 descents to restart the count at a
  cycle's entry: `cannot-say` is an honest answer and they share no code to do it
  once.
