# 26.1090: a registry's default is a cell of its type

Status: recorded
Date: 2026-11-18
Source: 26.1080's "not yet"

**A `default` was checked to be a string and nothing more.** It is written
as it would be stored, so it is a message of the cell's type and within
the entry's bounds like any value -- and a default no reader accepts is met
by the first program that falls back to it, on the device, rather than by
the schema's author.

## The rule

When a schema is analysed -- every command that generates from it -- each
registry entry's default is handed to that registry's own `check`, through
the Python accessors built in memory as `situc verify` builds them, and a
refusal is an error at the `default` with the type's own complaint as its
note: `"14x"` is not one of `time_unit`'s spellings, `"3651d"` is outside
`archive/gone`'s bounds.

`situc map` and `wire` describe a schema without analysing it, and do not
ask.

## Measured

`test_a_registry_default_is_a_cell`: a default the type refuses, one past
the entry's bound and one not minimal are each refused; a good one passes.
