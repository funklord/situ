# 26.792: An `indexed` region's elements are validated

Status: recorded -- fixed
Date: 2026-11-01
Source: 26.789's "not yet"

    struct btree_leaf_page {
        u8 page_type [must_eq = 13]; u16 first_freeblock; u16 cell_count;
        u16 content_start; u8 fragmented_free;
        indexed(offset_type = u16, count = cell_count, base = page_type) {
            table_leaf_cell cells[];
        }
    }

sqlite's leaf page is the corpus's one `indexed` region, and its cell has
checks of its own. The region's table was held to the frame and its cells
were not looked at.

## The change

- **The four backends** walk the table through the region's own `_at`
  (`cells_at`), which finds each cell by its offset and narrows the view
  to the cell's extent. Each cell then goes through its own `check`, and a
  refusal names the region.
- **An entry pointing where the frame holds no whole element is BOUNDS.**
  The first version skipped such an entry on the grounds that which
  offsets a table may hold is the region's business. It then passed a cell
  whose payload overran the page, which is the same lie as an element of a
  counted run the frame does not hold, and that is BOUNDS (26.676).
- **Python's `_at` narrows without asking** whether the region holds the
  element, where the other three refuse it. The loop checks the element's
  end itself.
- **The image names the base member.** A table measured from a member
  (`base = page_type`) recorded only that it was a member, not which, so
  neither walker could find a cell. The index record gains a fifth word,
  the member's placement. `INDEX_BYTES` is 20, and both loaders read by
  stride, so an older image finds `NONE` and the walkers decline it.
- **Both walkers** read each entry in the region's own terms, add the base,
  measure the element and validate it. The checks are the four's: past the
  frame, short of its minimum, then its own rules.

## Not done: an element taking arguments

No corpus run has one. Its `check` takes the arguments, so the run would
have to supply them, and which values are meant is the schema's to say.
That needs a design rather than a loop. `situc verify` still names such a
run in its note.

## Tests

`test_a_run_validates_its_elements.py` gains five sqlite pages: one cell,
two cells, a cell overrunning the page, a second cell overrunning it, and
an entry pointing past it. All four backends and both walkers agree. With
`situc` and `walker` reverted, both cases fail.
