# 26.838: the baseline, and the first check that needs one

Status: recorded -- `_baseline` ported to Python on the shared helpers, and
the `reserved` kind on top of it; two of the four remaining kinds now need
only the arm and version preludes
Date: 2026-11-03
Source: 26.834, which sized this; `situc/codegen/c/checks.py`

## Why the baseline comes first

26.834 said the three remaining constraint kinds share one prerequisite and
that the next run should port it as its own piece rather than discover it
underneath `must_eq`. That held, and the reason is worth keeping in one
sentence:

**A constraint check that only breaks a field proves nothing.** For
`must_be_one` a zeroed buffer already breaks the policy, so the check would
pass against a validator that did nothing. What gives a refusal its meaning
is that the RIGHT value was accepted first -- which needs a buffer
satisfying every OTHER constraint the struct declares, built before
anything is broken.

## What moved, and what that bought

Six functions went to `situc/codegen/__init__.py` ahead of this
(`placed_bytes`, `required_run`, `required_pattern`, `selected_arms`,
`digit_pattern`, `reserved_policy`). Each answers a question about values
and byte positions rather than about source text, so none is a backend's
business, and the move was proved byte-identical over all 43 schemas'
`--target c` output.

The payoff is visible in the generated code. For `example/rtc`'s
`wall_clock.<reserved0>` the two backends now emit the same arithmetic,
byte for byte:

    C       buf[3u] |= 0x01u;  buf[4u] |= 0x01u;  buf[5u] |= 0x01u;
            buf[1u] = (uint8_t)((buf[1u] & (uint8_t)~0x80u) | 0x80u);

    Python  raw[3] |= 0x01;  raw[4] |= 0x01;  raw[5] |= 0x01
            raw[1] = (raw[1] & 0x7f) | 0x80

Not because one was written from the other, but because both read it from
the same place. Two backends agreeing is evidence only when they are not
each computing the answer, which is the distinction `situc/codegen/differ`
exists for one level down.

## The control

Making the emitter's bit-level reserved check unreachable **fails 41 of the
43 checks across 12 schemas, and every one of the 41 is this kind.** The
five kinds before it catch none of it. The two that stay green are byte-run
reserved fields, which the emitter enforces at a second site -- worth saying
rather than rounding to "all", since the gap is where the next sabotage
should aim.

## What it does not see, and the branch that proved it

`own_entries` yields a struct's OWN members. Of the corpus's 83 reserved
fields it yields 53; the other 30 are 10 array elements, 9 inside variant
arms and 11 excluded for other reasons.

The first version of this emitter had per-field declines naming the array
and arm cases -- and **a fixture putting a reserved field inside a variant
arm produced neither**, because the exclusion happens upstream and those
placements never reach the emitter at all. A reason nobody can reach is
worse than no reason: it reads as a case that was considered and handled.

So those populations are named once in the preamble, where a reader of the
generated module meets them, and the per-field declines that remain are the
four a member can actually hit: a pinned run, bits past the struct's own
extent, no satisfiable baseline, and bits the map cannot place.

**The general form is worth more than the instance.** A decline is a claim
about a population, and a claim about a population wants the population
counted. Writing the branch first and measuring second is how a dead branch
gets committed looking like diligence.

## What remains

`must_eq` and the enum kind are the other two constraint checks and both
now want only what `--target c` wraps around the baseline: `_select_arm`,
which puts the discriminant where the member under test is in the message,
and `_reach_version`, which puts the version field where every versioned
member is present. Those two are also what the 9 arm-resident reserved
fields wait on, so porting them widens this kind as well as unlocking the
next two. The framing kind needs none of it.

Six of nine, asserting `OFFSET`, `SIZE`, `MUTATE`, `REPR` and now the
constraint axis.
