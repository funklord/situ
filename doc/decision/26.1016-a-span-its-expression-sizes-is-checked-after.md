# 26.1016: a span its expression sizes is checked after

Status: recorded
Date: 2026-11-14
Source: the goal gap -- builder refusals over the example schemas

**An RTP packet could not be built.** `padding[padded_flag * last]`
multiplies two fields, the second being the packet's own last byte, and the
C builder refused any byte run whose size expression it could not solve
for a single field. ID3's frame (`content`, sized by a synchsafe integer
spread over four fields with `|`) and QUIC's Initial (`payload`, sized
`length - (number_length + 1)`) were refused the same way.

**But none of them needs solving.** The caller passes every field the
expression names, and the bytes. What a builder cannot do is choose the
fields for the bytes, and it does not have to: once the message is whole
the reader's own `_len` says how long the run must be, and a disagreement
is refused (CONSTRAINT). The reader's `_len` stops at the bytes there are,
so a stated length running past them gets through that comparison and
`_validate` then refuses it as truncation. A writer holds the whole message
and cannot have been cut short, so in a builder with such a run that BOUNDS
is reported as the disagreement it is, CONSTRAINT.

The route is taken only for a byte run sized by an expression rather than
a bare field, that the inversion pass declined, in a struct taking no
arguments; everything else keeps its refusal -- cpio's `align_up` padding
among them. C only: the other three
builders refuse such a run. They plan from C's parts, and before they were
told to refuse it Python returned a packet for a last byte of 2 over three
padding bytes, and for padding with P clear.

**And a fault the work found.** A counted array of values -- RTP's CSRC
list -- refused a null pointer at a count of zero, which is nearly every
RTP packet. It is refused now only where something would be read from it.

**Measured** against RFC 3550 section 5.1: `80 60 00 01 00 00 00 a0 12 34
56 78` and the payload, then the same with P set and three padding bytes
ending in 3; a last byte of 2 or 5 over three bytes, and padding with P
clear, refused. An ID3v2.4 TIT2 frame per the structure document section
4, a size of 4 over three bytes refused; a QUIC version-1 Initial per RFC
9000 section 17.2.2 with Length 17, and 18 refused.
