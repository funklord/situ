# 26.799: 0068 step 2 -- a nested member takes its arguments

Status: recorded
Date: 2026-11-02
Source: 0068, step 2

    struct entry { parameter u16 block [stream]; u8 tag; u8 data[block]; }
    struct note  { parameter u8 mode; u8 v [max = mode]; }
    struct vol   { u16 block; entry(block = block) ent; note(mode = 3) k;
                   u8 after; }

This builds and the four backends agree on it: where `k` and `after` sit,
what `validate` says, and how much `required` asks for.

## What is built

A single member of the struct itself, named with its arguments, of a
struct other than this one. The refusal stays for every other shape:

- a run (step 3) and an arm (step 4);
- a member inside a block;
- an argument that hands on the parent's own parameter. The parent's
  offset functions would then need its argument tail wherever the child is
  measured, and that is built with self-reference (step 5);
- a child that can contain itself through any chain of members, which is
  measured with a depth (step 5).

## The layout

`Placement.arguments` carries `(parameter, source)` pairs in the order
written, as `located` carries its source, because every backend renders
the expression with `_over_fields` in the parent. `arguments_ast` keeps
the trees for the packer.

**An argument is held to its parameter's type.** The layout has the
intervals, so it is checked there: `u16 n; note(mode = n) k;` is refused
when `mode` is a `u8`. Converting it instead gives four answers, because C
and C++ truncate, Rust wraps and Python keeps the value.

**No new lattice row.** 0068 expected a parent field bound to a moving
child parameter to become a driver "exactly as a field named in `[len]`
is". Measured, a length field carries no weakening of its own in the map.
What it does carry is invalidation: its setter bumps the message
generation. `traverse.invalidating_members` now counts an argument's
source as a read, so `vol.block`'s setter invalidates as `n`'s does in
`u8 n; u8 a[n];`. It counts every argument, not only `[stream]` ones. A
meaning-only argument moves nothing, and invalidating on it is the safe
side.

## The four backends

Each gains one helper that renders the arguments in the parent, in the
order the child declares its parameters. Each call into the child that a
single nested member makes then passes them.

- **C** `_child_args`: the site extent and sub-view (`situ_entry_extent
  (whole, situ_vol_block_get(view))`), the nested `validate`, and the
  nested `required`. `situ_<child>_extent` now takes the child's argument
  tail. Its body reads the argument and no parent had ever called it, so
  until now it was emitted naming an undeclared `arg_block`.
- **C++** `_child_args`: the constructor at the sub-view and the extent,
  and `required`, where the arguments come before `need`.
- **Rust** `_child_fields` and `_child_args`: the struct literal at the
  extent and the accessor, and `required`. Each value is cast to the
  parameter's type, which the layout has shown it fits.
- **Python** `_child`: an argued class gains `_over`, which builds a
  view and puts the arguments on it without `at`'s minimum check, since
  the parent holds the frame. The parent builds the child through it. The
  nested `required` takes the arguments as keywords, rendered over
  `probe`.

The C caller of a C child view supplies the argument itself, as it does
at top level, because a C view carries none. The others carry it on the
child view.

## The image and both walkers

A new section, ARGUMENTS (`image_section_tag` 28, `image_argument`): one
row per (member, child parameter) with the program computing the value,
compiled against the parent the way a size program is. An image of a
schema with no argued member carries no such section, so every existing
image is byte-identical, and a walker older than the section skips it.

- **Python** `walk.child_args(view, index)` evaluates each row over the
  parent's view. The nested extent in `size_bits` and the nested
  `validate` in `report._validate` build the child view with those
  arguments.
- **C** `child_binding` copies the binding with the child's arguments at
  their ordinals and `arg_shape` set to the child, so `argument_of` reads
  them as it reads a caller's. The nested extent in `size_bits_deep` and
  the nested `validate` in `validate_deep` walk the child under it.

Before this, the C walker did not decline. It answered BOUNDS, a wrong
verdict, for a struct holding an argued member.

**What a walker still cannot say.** A bound naming a parameter
(`[max = mode]`, 26.798) does not encode, so the packer marks that struct
not validatable and both walkers answer `cannot-say` for it and its
parents. That is honest and sits outside this step.

## The wire signature

A member row carries `args block=block`. `note(mode = 3)` becoming
`note(mode = 4)` changes what a peer must send while no row of `note`
moves, and `wire --check` now sees it. The capability map is unchanged.
An argument changes no capability, and `situc diff` says so.

## The corpus

`edges.situ` gains `hands_on`, which hands `negotiated` its argument once
from a field and once as a constant. `negotiated` was already the corpus's
argued struct, with a variant and a nested arm behind the argument. The
Rust subtraction floor in `test_a_generated_length_never_wraps.py` moves
from 132 to 134 for the two nested accessors this adds. `doc/grammar.ebnf`
gains `arguments`, and the committed `.map` and `.wire` of `edges` and
`std/image` are regenerated.

Most of what the corpus struct found was the sweeps it exists for. Rust
refused `(probe.block() as u8)` as needless parentheses under `-D
warnings`. The walkers raised `Unsupplied` under the dissector and walker
agreement sweeps. The grammar could not derive `edges`.

## Tests

`test_a_parent_hands_its_child_an_argument.py`: the four backends on four
messages (two well formed, a broken rule, a frame too short); both walkers
and the four on a schema whose argument sizes the child; and the three
refusals that remain (a value that does not fit, a parent
parameter, a run). `test_a_parent_supplies_arguments.py` moves the field
and constant sources from refused to accepted.
