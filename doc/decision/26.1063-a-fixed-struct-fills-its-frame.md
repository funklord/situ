# 26.1063: a fixed struct's frame is the message, and a nested one's itself

Status: recorded
Date: 2026-11-17
Source: putting `[fills_frame]` in the corpus, where no schema held it

**`[fills_frame]` was vacuous in three backends for a fixed-size struct.**
26.981 made `struct s [fills_frame]` refuse bytes after `s` in its frame
and measured it over fuzznet's message, whose last arm runs to the
frame's end. A fixed struct's view in C, C++ and Python was cut to the
struct's own size, so the frame was the struct, `remaining` never
exceeded `size(s)`, and all three accepted `01 02 03 04` for a three-byte
struct that Rust and both walkers refused.

**And Rust broke the other half.** 26.981 says the rule holds by
construction for a nested struct, every reader handing it a view of its
own extent. Rust's accessor for a fixed nested struct handed it the rest
of the parent, so `holder { exact inner; u8 after; }` was refused by Rust
alone for `after`.

## The rule

The same held for any `when` reading `remaining` on a fixed struct
(26.980), the one `[fills_frame]` implies being one of them. The root view
of a fixed struct with such a `when` takes the rest of the message as its
frame -- C's `_view`, C++'s `at` and Python's `at` keep
their signatures and check that the struct fits -- which is what Rust's
`new` and the walkers already took. `traverse.takes_its_frame` is the one
predicate. Rust's fixed nested accessor cuts the slice to the child's
size, as the other three cut it.

## Measured

`test_a_fixed_struct_fills_its_frame.py`: the four backends and both
walkers over `01 02 03` (0), `01 02 03 04` (2, the `when`) and `01 02`
(no view), and `holder` over `01 02 03 09` (0) in all four; and a fixed
struct whose `length` says what follows, `when 2 + sized.length !=
remaining`, over `01 02 aa bb` (0) and one byte more (2). With the
predicate forced false, C answers 0 for the trailing byte again; keyed on
the attribute alone, it answers 0 for the written `when`.

Found by a census of implemented attributes no tracked schema uses:
`fills_frame`, `[limit]` alone (26.1047), `tag_order`, `truncated` (an
AEAD tag's, which no reader computes) and the drive layer's resend
policies. The first three went into `edges` with this.
