# 26.987: gen-checks places a fixed wide run

Status: recorded
Date: 2026-11-13
Source: `example/gitidx`, the second thing it found

`gen-checks` builds one instance of a struct with no worst case and asks
each member where it starts. A run of values wider than a byte has an
indexed getter and no pointer, so it has no answer and is skipped -- but
only where its count is not fixed. `u32 fanout[255]` has a fixed count,
so the generated suite called `_fanout_ptr`, which no backend emits, and
did not compile. The instance check visits only structs with no worst
case, so `radiotap`'s `u16 he_data[6]`, in a fixed struct, never asked,
and git's pack index was the first to.

A wide run is skipped whatever its count now.
`test_gen_checks_place_a_fixed_wide_run` builds and runs the generated
suite for the smallest such struct, and fails with the change reverted.
