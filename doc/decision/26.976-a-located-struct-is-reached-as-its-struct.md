# 26.976: a located struct is reached as its struct

Status: recorded
Date: 2026-11-12
Source: walking the goal gap -- the TIFF oracle built a directory by hand

A member placed by `at` whose type is a struct -- a TIFF's first
directory -- was handed back as bytes by C++, Rust and Python, and a
caller took the struct over them by hand: the offset again, the length,
and every argument the member hands its type. The TIFF oracle did
exactly that, `ifd.at(msg, ifd_offset, len(first), arg_order=...)`.
C has always given `situ_<struct>_<member>_view`.

Each of the three now has `<member>_view` beside the bytes: Python a
property returning the struct, C++ `first_view(msg, out)` with the view
owned by the message, Rust `first_view(msg) -> Result<Ifd>`, each handed
the member's arguments. The oracle uses it, and
`test_a_located_struct_is_reached_as_its_struct` reads SHORT widths laid
out by hand through it in both byte orders.
