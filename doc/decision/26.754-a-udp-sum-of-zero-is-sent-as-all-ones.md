# 26.754: A UDP sum of zero is sent as all ones

Status: recorded -- fixed
Date: 2026-10-30
Source: `project.md` section 26; reported in `suggestion/hull.md` section 20

RFC 768: "If the computed checksum is zero, it is transmitted as all ones
... An all zero transmitted checksum value means that the transmitter
generated no checksum." `example/udp`'s `internet_checksum` was
`ones_complement(width = 16, complement)`, and every backend wrote what
the kernel yielded -- so a datagram whose ones'-complement sum is 0xFFFF,
one in 65,536, went out with a zero sum, which a receiver reads as "none
sent". hull found it moving its switch's UDP answers onto `example/udp`.
TCP has no such rule; IPv4 and ICMP neither.

## The fix

**`zero_means_none`**, a third argument of the `ones_complement` kernel,
and both halves of the rule read it through `kernels.zero_means_none`:

- the derived kernel in C, Rust and Python returns 0xFFFF where the sum
  comes out zero (C++ calls C's);
- `verify` in all four backends accepts a stored zero.

`example/udp` carries the flag. `std/kernels.situ`'s `internet_checksum`
does not, because it is the sum IPv4, ICMP and TCP use, and none of them
gives a zero that meaning.

**And the walker's kernel**, which the editor recomputes a checksum with,
had dropped both flags: the image's ones'-complement row carried only the
width, and `walker.derived` complemented every sum -- wrong for
`edges.summing`, which is uncomplemented. The row now carries `complement`
as its `xorout` (0xFFFF, which for a 16-bit sum is exactly the complement)
and `zero_means_none` in its last word, two fields this family had no use
for, so the row's size is unchanged.

`example/udp`'s committed map and wire are unchanged: a kernel argument
reaches neither.

`test_a_udp_sum_of_zero_is_sent_as_ones.py` asserts the kernel's answer
in three languages with and without each flag, `verify`'s answer for a
stored zero in Python, the emitted comparison in C, C++ and Rust, and the
walker's kernel; nine of its fifteen fail with the change stashed, the six
that pass being the cases without the flag.
