# 26.977: generated C suites need no framework

Status: recorded
Date: 2026-11-12
Source: the holder -- "Is cmocka strictly necessary, or could it even be
better if you generated the entire tests directly? Test frameworks are often
dwarfed by the code needed for tests, and are sometimes in the way of
testing." -- and the go-ahead to replace it

**What situ hands a user now asks for a C compiler and the runtime.**
`gen-checks`, `gen-tests` and `gen-codec-tests` emitted cmocka suites, so
running a file situ wrote meant installing a test framework first; the
cross targets could not run them at all, cmocka having no aarch64 build
here (which is why `test/cross/probe.c` was already a self-checking
program); and the C++ suites have been a plain `main` from the start, for
section 24's reason.

What was used of cmocka was assertions, a list of tests and a runner --
no mocks, no `--wrap`, no fixtures. `situc/codegen/c/selfcheck.py` is that,
about sixty lines of C each generated suite carries inline: `situ_check_eq`
and its siblings report where and what -- both values of an equality, the
first differing byte of a compare -- and leave the test by `longjmp`, as
cmocka does, so the next test runs; the runner prints the lines cmocka
printed and exits non-zero when anything failed. Everything is `static
inline` or a macro, so a suite using half of it still builds under
`-Wall -Wextra -Werror`.

The generators were renamed mechanically, and the change carries its
proof: every corpus schema through the three generators before and after,
167 files, and each new file with the names mapped back and the prelude
removed is the old file minus its cmocka includes, byte for byte.

**The hand-written suites in `test/generated` moved too**, so the tree no
longer needs cmocka for anything. They include `situ_check.h`, which the
Makefile writes from `selfcheck.py` -- one copy -- and gained three checks
only they use (`situ_check_ptr_eq`, `situ_check_str_eq`,
`situ_check_bytes_ne`).

`test_a_generated_suite_needs_no_framework.py` builds and passes a
generated suite with no library beyond the runtime, and holds the runner
to failing: a failed equality and a failed byte compare each fail their
test with the values printed, the next test runs, and the program exits 1.
