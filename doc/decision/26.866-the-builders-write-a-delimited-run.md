# 26.866: The three builders write a delimited run

Status: recorded -- 195 builders over 30 schemas, 76 of them an arm. Tagged
records are the largest slice left
Date: 2026-11-05
Source: 26.865's measure

A run of bytes a delimiter ends takes the caller's bytes and writes the
delimiter after them, in C's two forms.

With no escape, a run holding the delimiter would read back short, and is
refused. With `[escape]` the caller hands over content and the wire form is
the schema's. Exactly two kinds of byte carry the escape: the delimiter's
first byte where it begins one, and the escape itself. `[max]` is left to
`validate`, as in C, since the cap is on content and delimiter together.

A size field measuring a delimited run is declined, the delimiter not being
the caller's to count.

`test_a_nested_member_is_one_whole_message.py` holds all four to the bytes:
one- and two-byte delimiters, the refusal, and both escaped bytes. Removing
the refusal in Rust and either arm of the escape test in Python and C++ fails
it. The differential hands an escaping run content that needs it.
