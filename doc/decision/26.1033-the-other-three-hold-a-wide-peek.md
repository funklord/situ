# 26.1033: the other three hold a wide peek

Status: recorded
Date: 2026-11-14
Source: 26.1028, which was C's alone

**26.1028 let C build an arm whose peeked discriminant is wider than its
first byte** -- Matroska's eight-byte Cluster size -- by asking the
reader's getter for the peek once the message is whole. Python, C++ and
Rust refused such an arm. Each of their readers has the same getter
(`written`), so each builder now asks it as C does: the arm's case, or
none of the named ones for the default arm.

**Measured** where nothing else can refuse: on a schema whose two arms hold
one struct that takes any two bytes, the named arm handed `12 13` is
refused in all four and the default arm writes them -- the agreement test
comparing the four's bytes and verdicts -- and Python refuses `01 02` handed
to the default arm.

Still C's alone from this stretch: a checksum packed into bits (26.1027),
because C++'s reader emits no `_store` for one and the three share one
test of what they serve.
