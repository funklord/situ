# 26.1067: the dissector checks no span the frame cut short

Status: recorded
Date: 2026-11-18
Source: the next lens from cb6ce2ac, asked of the seventh reader

**The dissector summed a covered span whose declared length the frame did
not hold.** cb6ce2ac found both walkers judging a covered run complete by
where its last member ends, so `options[count]` running past the frame,
followed by `text[remaining]` placed back inside it, was summed where all
four backends refuse. The dissector had the same fault by another road:
every run it walks advances `at = math.min(at + len, tvb:len())`, so after
an overrun the cursor sits at the frame's end, `remaining` starts there,
and the span's end mark is a byte the frame holds. `0a 0000 aabb` -- a
count of ten in a five-byte frame -- was shown `Bad, should be 0x3a55`
with a CHECKSUM expert, a verdict on a message every other reader calls
malformed.

**Nothing compared it.** `test_the_dissector_agrees_with_the_walker`
compares the two only on keys both print, and a walker's `sum refused`
printed no number, so the dissector's number was never held to anything.
And no corpus schema had the shape: cb6ce2ac's reproduction lives in one
test file, so none of the sweeps asked it.

## The rule

- **A run the frame cuts short is counted**, on `situ_check.short`, at
  every place the dissector stops one short: a counted run's clamp, a
  fixed text number's clamp, a counted run of structs or records ending
  before its count, and an element walk stopping on an element whose own
  size passes the frame. The counter exists only where a tag is checked,
  on the table that already holds the kernels, so it costs no Lua local.
- **A checked tag marks the counter where its span starts and where it
  ends, and checks only if nothing was cut in between** -- the end mark,
  not the check, so a cut between the span and a tag placed after it
  does not suppress the check. A cut span gets no status row, as a span
  the frame does not hold already got none. `covers(before)` keeps its
  own test, the message ahead of the tag.
- **The differential holds the verdict, not only the number**: the
  walker's `.sum` line becomes `#shown` 1 or 0 (summed or refused), the
  dissector's status row `#shown` 1, so a status beside a refusal
  disagrees.
- **`edges.overrun_summed`** carries the shape, so every sweep asks it on
  random draws -- the four backends, both walkers, the dissector.

## Measured

Before: `0a0000aabb` shown `Bad, should be 0x3a55`. After: no status;
`020000aabbcc` is still `Bad, should be 0xbe76` and `02be76aabbcc`
`Good`. Removing the `not cut` condition fails
`test_the_dissector_agrees_with_the_walker[edges]` on four draws
(`overrun_summed.sum.sum#shown: the dissector shows 1 and the walker
reads 0`, the tag since renamed `check`: a second tag named `sum` in edges
collided with `test_the_four_backends_say_what_the_walkers_say`).
