# 26.1014: a builder writes a trimmed run

Status: recorded
Date: 2026-11-13
Source: the goal gap -- builder refusals over the example schemas

**SMTP's `command` could not be built**: its argument is `u8 argument[]
until "\r\n" max 512 [trim]`, and every builder refused a trimmed run
because "the bytes it holds are not the bytes it was given". They are,
exactly when the content neither starts nor ends with a byte its reader
trims. So all four builders now refuse such content as a constraint
violation and write the rest as given, which reads back unchanged.

**Measured** with RFC 5321's `MAIL FROM:<a@example.org>` and its CRLF,
built byte for byte in Python and C and read back through the reader; an
argument with a leading or a trailing space refused. The four builders
agree on `command`.
