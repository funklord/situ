# 26.1087: a registry is generated in Python

Status: recorded
Date: 2026-11-18
Source: 0070, step 6 -- fuzzypickles' client re-modelled fuzznet's settings
in Python-side terms and lost what did not fit (fuzznet sec 1099)

**The C registry (26.1081) in Python's idiom.** Each registry is a class:
its `Entry` -- key, family, safe, bounds, default, unit, summary, window,
the cell's type, and one integer per declared policy, each word a bit
(`SCOPE_ESTATE`) -- its `ENTRIES`, and `find`, `check`, `value` and `safer`
as static methods. `check` raises the cell type's own error where the bytes
are not a cell, as `validate` does, and `ConstraintError` for a bound the
entry states; `value` is None where `check` would raise.

The module passes `mypy --strict`: `Entry` is typed field by field, and
each cell type's view has a name of its own.

## Measured

`test_a_registry_is_generated_in_python`: the 33 cases the generated C and
both walkers answer, and `mypy --strict`. Sabotaged: a family word of any
character fails it.
