# 26.777: The selected arm must fit the frame

Status: recorded -- fixed
Date: 2026-10-31
Source: `project.md` section 26 (the lens 26.776 left)

    struct arm { u8 k; variant held switch (k) { case 1: u32 four;
                                                  case 2: u8 one;
                                                  default: error; } }

A variant whose arms differ in size declares no length and may sit at a
constant offset, so `_fits_check` -- which asks about a member that
declares a length and about one at a dynamic offset -- asked nothing of
it in all four backends, the shape 26.776 found in coded regions. `k = 1`
in a two-byte message validated clean while the arm's own accessor
refused it and `required` asked for five bytes.

Each backend's `_fits_check` now asks `_variant_fits`: the variant's
offset and the selected arm's length (`_variant_length`, zero for an
unknown discriminant, whose own refusal follows) must fit the frame. An
arm that is a nested struct is measured by its extent, which its own
validation already held to the frame; a scalar arm had nothing. An arm
that is itself variable is clamped inside `_variant_length`, which is
26.689's case and stays open.

The Python walker had the same gap on one path: its `_arm_validates`,
which the default arm reaches, returned before the fit check for any arm
that is not a struct -- the shortcut the C walker's `arm_validates`
records removing for `dnsname.label`. The differential found it the
moment C refused netlink's default `opaque rest[nlmsg_len - 16]` claiming
more than the frame: C now refused, the Python walk still accepted. It
now measures every arm but an unmeasurable struct, and checks a scalar
arm's constraints as the matched path does.

The corpus changes by the new check in the nine schemas with a
variable-size variant -- `dnsname`, `id3`, `json`, `keystore`, `modbus`,
`mqtt`, `netlink`, `sexpr` and `edges` -- and `check` identifiers move
where a variant gained one.

## Tests

`test_the_selected_arm_must_fit.py`: the four refuse the short arm,
accept whole ones of both sizes, and still answer VERSION for an
unknown discriminant. With the change reverted the short arm validates.
