# 26.752: Two backends gain the gated readers they lacked

Status: recorded -- fixed; supersedes 26.750's table
Date: 2026-10-30
Source: `project.md` section 26

**26.750's table was wrong about C++, and so about the split.** It was
measured with a grep that did not match C++'s spelling of a gated reader,
`::situ::rt::bytes x() const`, and so recorded C++ as having none for a
fixed run where it has one. Measured again in each backend's own spelling:

| run inside a gate | C | C++ | Rust | Python |
|---|---|---|---|---|
| fixed `u8 x[2]` | `_ptr` | yes | yes | **none** |
| sized from outside | yes | yes | yes | yes |
| sized from inside | none | none | none | none |
| `u8 x[remaining]` | yes | **none** | yes | yes |

C's fixed run has `_ptr` and no `_len` gated or not -- a fixed length is a
constant, and the framed probe already answers it from the count -- so it
is not a gap. A run sized from a field inside the region is declined by
all four, which is consistent rather than split. Two real gaps remained,
and both were one line:

- **Python** declined a gated fixed run: its gate asked
  `_length_expression`, which answers for a run the data sizes and has
  nothing for a count the schema wrote. The length is now the count.
- **C++** declined a gated `[remaining]` run: its count path has no field
  to read for `remaining`. The length is now what the frame leaves after
  the run's start, which is how the other three read it.

## The probe

The differ's `SEALED` probe asks for fixed and `[remaining]` runs again,
each carrying its count where the schema fixes one. C answers a fixed run
as its framed probe does -- `n = ptr == NULL ? 0 : COUNT`, the pointer
being NULL unless the whole run fits. Without the NULL test the first
version read `ptr[n - 1]` off a NULL pointer and the C driver died on a
gated run past the frame, which the sealed cells of the composed sweep
showed at once.

Forty sealed `fixed` and `remaining` cells agree. The corpus's three gated
probes are unchanged. `test_the_gated_probe_asks_what_all_four_read.py`
holds a fixed run's answer and a `[remaining]` run's agreement; each
backend's fix fails its test when reverted.

## Still open

A run sized from inside the region leaves the region without a length in
some backends, so C cannot place a `tag` after it and declines that tag's
reader -- and the driver's `TAG` probe asks the schema rather than the
emitter, and calls it. 26.733's shape, one member over.
