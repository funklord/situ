# 26.1120: a replay window, stated in the schema

Status: recorded; design, not yet built
Date: 2026-11-20
Source: fuzznet (inbox 20261120T1231Z, item 3; its sec 1311): "Which
nonces, times and message numbers a receiver accepts once: a window over a
counter or a time, per sender, with its size in the schema. 357 lines here."

## What fuzznet does by hand, measured

Two mechanisms, read from its tree:

- **A counter window per session** (`wire/session_frame.c`): a frame's
  counter is refused if heard before or older than the window --
  DTLS's and IPsec's sliding bitmap (RFC 6347 4.1.2.6, RFC 4303 3.4.3).
- **A nonce set with expiries** (`frame/freshness.h`): a fixed capacity
  the caller hands over, a horizon (`now < expires_at <= now + max_ahead`)
  so a frame cannot pin a slot for a century, the caller's clock, refusal
  rather than eviction when full, and nothing recorded for a refused
  frame -- so it runs after the tag verifies and a forgery spends no slot.

## Where it sits

Rung 5, `converse` (0032): the first rung that may hold state between
calls. Like a relation, it is a predicate over messages; unlike one, it
remembers. It is stated in the schema because both peers must agree on it
-- a window one side sizes at 64 and the other at 32 is a protocol
disagreement, and fuzznet's own note finds the expiry's UNIT stated
nowhere. The state is the caller's memory, handed over, as every rung
above `edit` takes its backing (26.99).

## The shape proposed

    replay session_counter(f: fzn_frame) [key = f.head.sender,
            counter = f.head.seq, window = 64];
    replay fresh(f: fzn_frame) [nonce = f.head.nonce,
            expires = f.head.expires, capacity = 4096, ahead = 30000];

Each generates a state type the caller allocates (one per key for a
counter window; one table for a nonce set) and `admit(state, view, now)`
answering OK, REPLAY, TOO_OLD, HORIZON or FULL -- recording only on OK.
`admit` takes a VERIFIED view where the fields it reads are behind a gate,
which is item (2)'s question and is answered with it: the window is asked
after the tag, never before.

## Open before building

- Whether one declaration kind (`replay`) with two forms reads better
  than two words.
- The clock's unit: stated on the declaration (`[unit = ms]`), since
  fuzznet found it stated nowhere and two peers must agree.
- Built in all four backends, as every rung is; the walkers have no
  state and answer nothing here.
