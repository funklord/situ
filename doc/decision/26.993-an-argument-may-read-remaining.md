# 26.993: an argument may read remaining

Status: recorded
Date: 2026-11-13
Source: the copyright holder's answer to 26.991's run question -- "bound
remaining in argument checks only" -- for hull's "each frame lies inside
the data"

hull's pack index cannot say its frames lie inside the data: an entry
knows the data's length only if the pack hands it as an argument (0068),
and the length is what `remaining` leaves after the index and the
manifest. An argument's range must fit its parameter, and `remaining` had
no upper bound in the solver.

**Bounded where an argument is checked, and nowhere else.** `Env` carries
a `remaining_max`, None everywhere and `VIEW_BYTES_MAX` -- 2^32 - 1, the
longest frame a 32-bit view describes in C, C++ and Rust -- in
`arguments_of` alone. A member sized by `remaining` keeps an unbounded
capability, so no map moves.

**What it means there** is what it means in a size (26.986): the bytes
from the member's start to the frame's end. Each backend renders it so,
and SIGNED: `remaining - count * 57 - manifest_frame` is room left, and
below zero is an answer that `uint32_t` arithmetic would have wrapped to
four billion. The walkers already evaluated it so.

Two faults stood between the statement and a verdict, both met here
first:

- **C's `messages` took no arguments.** A `when` reading a parameter
  named `arg_room` in a function that had none, and the source did not
  compile. It takes `check`'s tail now.
- **A run's elements were walked only where a member check could
  refuse.** An element refusing only by a rule was never validated by
  the four backends, while both walkers held it: a run of hull's entries
  passed one past the data that the walkers refused. `_element_refuses`
  counts a `refuse` in all four.

On a copy of hull's schema -- `parameter i64 room`, `index_entry(room =
remaining - count * 57 - manifest_frame)`, `[max]` on `manifest_frame`,
and `when offset + frame > room refuse` -- `situc verify` conforms a pack
whose frames lie inside the data and refuses one with a frame past it.
`test_an_argument_may_read_remaining` asks the four and both walkers over
four packs and that `pack.data` stays unbounded. The corpus generates
identically in all four targets.

The dissector takes only a `[stream]` parameter (0050), so such a schema
has no dissector yet; that limit is older than this.
