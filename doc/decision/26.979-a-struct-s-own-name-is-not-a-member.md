# 26.979: a struct's own name is not a member

Status: recorded
Date: 2026-11-13
Source: trying fuzznet's "the schema cannot say yet" against its call schema

`when size(nothing) != 0` -- the struct's own name inside `size` -- and
`when nothing != 0` passed `check_whens`, because a path with no member
had nothing to step through, and all four backends raised `UnknownName`
out of the code generator: a traceback where 17.0 asks for a diagnostic.
`invariant s.len == s` was worse, taken without a word and maintaining
nothing; `invariant s.len == size(s)` crashed like the `when`.

Both are refused now, each in its own words: a `when` reads a struct's
members, an invariant derives from its fields, and `size(s.m)` measures
one. A struct's own extent is not offered, deliberately: the view a `when`
is evaluated against is handed its frame, and how long that frame is
against the struct is the framing layer's question (19.3's trailing
bytes), not a predicate's. `test_a_struct_s_own_name_is_refused_where_a_member_is_read`
holds all four spellings and fails 4 of 4 with the change reverted.

The probe that found it also answered half of fuzznet's list: "a piece
within its pieces" is `when frame.piece >= frame.pieces refuse ...`,
which every backend already evaluates through the arm that holds it.
