Status: recorded
Date: 2026-11-18
Source: 0070's walked registry -- its plainest count is `decimal u64
value[remaining]`

**Neither walker could validate an unsigned 64-bit text number over a span
nothing bounds.** Its ceiling, derived from its type, is 2^64 - 1; the
image's check row holds a signed `q`, which cannot, so the packer marked
the struct as one the image cannot validate and both walkers answered
"cannot say" for every message of it -- a registry's plainest count among
them, and any `decimal u64 x[remaining]` or delimited `hex u64` without a
`[max]`.

## The rule

- An unsigned ceiling past `q` is held as its two's complement; both
  walkers read the row unsigned for an unsigned member. The C walker
  already compared it as `uint64_t`; the Python walker's digits check and
  its lax read mask it now.
- A signed member's ceiling always fits, and is untouched.
