A checksum covers bytes that are not all written when it is reached, so its
place is kept and zeroed, and it is filled once the message is whole: computed
through the reader's own `<tag>_compute`, stored in the codec's order, then
`<tag>_check`ed, which is what proves the store. As in C. Rust takes a view
each time, since storing needs the buffer a view borrows.

A tag over a pseudo-header stays declined. Its prefix is the caller's to hand
over, and that is a parameter these three do not have yet.

The differential now runs `gen-derived`, since C and C++ link a codec's
implementation from it. `test_a_nested_member_is_one_whole_message.py` pins
all four to PNG's IEND chunk, `ae426082`, a published value rather than four
writers agreeing.

**A decline now names the part that keeps a struct out**, in place of a list
of the roles served that went stale with every record since 26.860.
