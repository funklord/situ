# 26.699: `--materialize` had no corpus-wide compile

Status: recorded -- gate extended; no defect found today
Date: 2026-10-27
Source: `project.md` section 26

**`--materialize` has shipped two breaks on its own, and neither
corpus-wide compile test read that mode.**

    26.486  `at += None;` in a materialized C++ header, from
            `test/schema/padded.situ` -- a committed schema
    26.697  a redundant paren pair that `-D warnings` refuses, in
            materialized Rust

Both were found by a constructed probe. `test_every_schema_compiles`
exists in the C++ and Rust suites and calls `generate_cpp` / `generate_rs`
with no `materialize` argument, so 46 schemas were compiled in one of the
two modes the flag offers. Both are parametrised on the mode now, 92 cases
each.

**No defect today.** All 46 materialized C++ headers compile under this
project's own warning set, and all 46 materialized Rust crates under
`-D warnings`, measured before the tests were changed. This closes a gate
gap rather than a bug.

**Cost, measured rather than assumed**, which is what made it an easy
call: C++ 4.07s to 8.34s, Rust 18.92s to 37.70s. Twenty-three seconds for
a mode with two shipped breaks.

## The control failed first, and the reason is worth more than the fix

**Reverting 26.486's fix did not turn the test red.** That entry's cause
was a `pad_to` falling through to an `else` which asked
`_length_expression` how long a PAD is; it answers None and the generator
formatted it. Removing the `align` branch with `pass` makes the step a
silent skip, which compiles -- so the revert produced a different program
from the one the bug produced, and 92 cases passed.

**Reverting a fix is not reproducing the bug.** What demonstrated the
coverage was sabotage instead: emitting an undeclared symbol from the
`align` branch turned the `padded.situ-materialized` case red while all 46
plain cases passed. That is the schema 26.486 shipped in and the mode it
hid in, and the plain half's blindness is the same fact from the other
side.

So the new coverage is live, and the evidence for it is a sabotage rather
than a history replay -- which is the honest form, since the history
replay was tried and did not work.
