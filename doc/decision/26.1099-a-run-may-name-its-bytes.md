# 26.1099: a run may name the bytes it holds

Status: recorded
Date: 2026-11-18
Source: 0070's open list -- fuzznet's ADDRESS host, letters, digits and
`.-:`, which `[encoding = ascii]` could only approximate

**A character class had no spelling.** ADDRESS's host is a run of bytes
each of which is a letter, a digit, `.`, `-` or `:`; an HTTP token is RFC
9110's `tchar`; a DNS label is letters, digits and `-`; a base64 or hex
body is its alphabet. Each is a run whose every byte is in a set, and the
nearest thing situ could say was `[encoding = ascii]`, wider by every other
printable byte -- so a schema promised less than the protocol, and each
consumer re-wrote the check by hand.

## The construct

`[chars = "A-Za-z0-9.:-"]` on a run of `u8` -- counted, sized, delimited
or to the end. The string is a class written as a regular expression's
bracket is without the brackets: characters, `x-y` ranges, a `-` literal
at either end, and the string literal's escapes for the rest. There is no
negation: a class says what a reader accepts, which is what a contract
promises, and "everything but" is a different promise every time the
domain grows.

It goes on a member of the struct itself, a transparent block included,
and is refused inside an arm or a sealed or coded region. An arm's member
is checked where its arm can be dispatched and not where it cannot -- C's
`_arm_guard` answers nothing for a `default` arm -- and a class some
readers enforce and others skip is a schema they disagree about. A struct
holding the run carries the class to wherever the struct is placed.

## One table

`situc/chars.py` parses the class into a set of byte values and computes
its 256-bit table, low bit first. Every reader checks each byte against
that table: C and C++ as a `static` array, Rust as a `const`, Python as a
`bytes`, and the image as four constraint rows (kinds 24 to 27), each
holding 64 bits of it, which both walkers join back. So no reader has its
own idea of what a range includes. The wire signature carries the class in
one canonical spelling -- ascending, a run of three or more as a range,
`-`, `"` and `\` as `\xNN` -- so two ways of typing one class are one
contract, and a comparison reads a narrower class as a tightening, a wider
one as a loosening, and two that overlap as the change that warns.

The dissector shows such a run as bytes and checks it no more than it
checks an encoding: it raises expert info for messages, ordering and
checksums, not field constraints.

## Measured

`test_a_run_may_name_its_bytes`: parsing and the canonical round trip;
five misplacements refused; four backends and both walkers agree on six
frames -- a run before moving the offsets, a refused byte in each of a
counted, a delimited and a to-the-end run, and an empty run.
