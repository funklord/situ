# 26.797: 0068 step 1 -- the arguments are parsed and checked

Status: recorded
Date: 2026-11-02
Source: 0068, step 1

`entry(block = hdr.block) files[n];` parses, prints back as written, and
is held to the rules that need no layout. Every shape is still refused by
the nesting rule afterwards, so nothing half-built is reachable.

## What is checked

`wellformed.check_member_arguments`, before `check_parameter_nesting`, so
an author meets an argument's own fault before the "not built yet" one:

- **The type takes parameters.** `u8(x = 1) a;`, or arguments on a
  struct that declares none, is refused.
- **Each name is one of its parameters, once.** An unknown name, a
  repeated one and a missing one are each refused naming it. There are no
  defaults.
- **An argument is arithmetic over names in scope.** A member declared
  before this one (a parameter is a member), a `const`, or an enum member.
  A call is refused, as `at` refuses one (`_check_located`). `min` and
  `max` could be allowed later, but no format here needs them.
- **Rule 5.** An argument to a `[stream]` child parameter may not read a
  parent parameter that is not `[stream]`. A meaning-only child parameter
  takes any source.

Whether a value fits the parameter's type needs the solver's intervals,
so it lands with step 2. The layout places the member and holds the
argument's range inside the parameter's scalar.

## The AST

`ast.Field.arguments`, a tuple of `ast.Attr` like `indexed(...)`'s.
Empty for every existing member, and `parse_member_arguments` reads it
only where a field's type is followed by `(`, which nothing else in the
grammar puts there.

## Tests

`test_a_parent_supplies_arguments.py`: the round trip, six malformed
arguments, a missing one, and four well-formed ones (a field, a `const`,
a `[stream]` parameter, and a meaning-only parameter fed from a
per-message one) that reach the nesting refusal. Every corpus schema still
maps.
