# 26.951: a delimited octal number reached the C generator

Status: recorded
Date: 2026-11-10
Source: a lens from 26.948 -- tables keyed on the radix that predate `octal`

**`octal u32 n until ":"` raised `KeyError: 8` out of the C generator.**
26.756 made `octal` a radix and held it on cpio's `odc` header, whose
numbers are all of fixed width. The delimited getter is another path, and
it named its base from a table holding ten and sixteen. C++, Rust, Python,
the dissector, the checks and the packer built the same schema.

26.948 found the first two such tables -- the unparser wrote `octal` back
as nothing, and `situc doc` said "base 8" -- and a search for every table
keyed on the radix found this third. `test_an_octal_text_number.py` holds
a delimited octal number in all four backends and both walkers: `12:` is
ten, and a `9` is refused.
