# 26.788: The map says a member after an arm's ended run has no setter

Status: recorded -- fixed
Date: 2026-10-31
Source: the lens from 26.785 -- a run test that names the counted shape

    struct S { u8 kind; u8 n;
               variant body switch (kind) { case 1: pt recs[] while (x != 0) max 4;
                                            default: u8 raw; }
               u16 after; }

26.779 added the map row `unwalked-arm-predecessor`. It gives the member
after a variant that no backend measures `mutate=Immutable` and
`access=Sequential`. `resolve._mark_unwalked_arms` picks those variants,
and it asked `is_counted_run`. Since 26.785, `offset_unresolvable`, which
the backends and the differential driver ask, also covers a run of
records that a `while` or a terminator ends. So for those arms the map
gave `after` a setter and random access while all four declined both.

## The change

`_mark_unwalked_arms` asks `is_unmeasured_run`, the same question
`offset_unresolvable` asks of an arm. The corpus has no such arm, and
its maps are unchanged.

## Tests

`test_propagate.py::test_an_arm_run_a_condition_or_terminator_ends_is_unwalked_too`,
for a `while` and a delimited run of fixed and of variable records.
With `situc/resolve.py` reverted, all four fail.
