# 26.1097: a discriminant or a length reads through nested structs

Status: recorded
Date: 2026-11-18
Source: openmlx4, inbox 20261118T1943Z item 1 -- FS2's sentinel, which
openmlx4 had held back believing situ would not switch on bytes inside a
CRC-covered body

**`variant rest switch (section.hdr.next)` was refused as "not readable
before variant `rest`".** openmlx4 read that as situ declining to steer a
parse by bytes inside `gph_section`'s authenticated body. Measured, it was
depth: `layout.record_nested_intervals` put a nested struct's scalars in
scope one level down and skipped every deeper path, so `s.hdr.next` was
refused in a plain struct as well, while `s.next` one level into the same
authenticated body always built.

## The rule

A path is readable before a variant, or as a length, at any depth, when
every step before its leaf is a nested struct held once at a place its
parent decides -- not a variant's arm, not a run, not a located member, not
a struct sized by an expression. Those still are not readable before: an
arm's member exists only in its arm, a run's element has no single value,
and a located member is wherever the message says.

## Also found: both walkers dropped a discriminant at an offset

The image's arms table carries a placement index and no base, and the
packer resolved `inner.kind` through `resolve_in`, which answers a base --
1 for `inner` a byte into `off_switch` -- that the arms table then dropped.
The C walker said cannot-say, and the Python walker said BOUNDS over bytes
all four backends accept: a wrong verdict, one level down, before this
record. Nothing in the corpus put a struct holding a discriminant anywhere
but at offset 0. The packer now gives such a discriminant the owner's own
flattened placement, whose offset is the owner's and whose base is 0.

## Measured

`test_a_selector_reaches_through_nested_structs`: two levels in scope, an
arm's member and a located member still refused; four backends and both
walkers agree on `deep_switch` and `off_switch`. With the layout change
reverted the two-level cases are refused; with the packer change reverted
both walkers disagree on `off_switch`. FS2's sentinel builds in all four
backends.
