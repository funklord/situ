# 26.868: An arm writes its own packed tag

Status: recorded -- 210 builders over 31 schemas, 87 of them an arm
Date: 2026-11-05
Source: 26.862, whose refusal cost C 24 arm builders

26.862 refused a packed discriminant, since a bit field took the caller's
value and could disagree with the body. That was honest and too wide: it took
dnsname, id3 and mqtt's `packet` away from C, which had built them. The parity
walk across targets showed it.

The arm now states the bits, as it does a whole-scalar tag. A named arm's
builder takes no parameter for them (`Part.stated`). The default arm's tag is
the caller's, and one a named arm claims is refused. All four writers do this.
So the mismatch 26.862 refused cannot be expressed. 26.862's status and 26.861's
claim that a tag cannot disagree with its body now hold for packed tags too.

mqtt's `connect_body` has flags that are each a packed tag of their own
variant, and is built since (26.874).
