# 26.809: 0068 step 6 -- the dissector hands a run its arguments

Status: recorded
Date: 2026-11-02
Source: 0068 step 6, the half 26.804 left declined

    struct runs { u8 block [max = 6]; u8 n; entry(block = block) many[n];
                  u8 after; }

A run of argued elements is dissected now. Rule 4 gives every element the
same values, so the run needs no per-element plumbing. The lines any run
emits are emitted unchanged and run inside one `handing(<type>_arg,
{...}, function() ... end)`, and each element's extent and dissector
find the parent's values in `<type>_arg`. `at` belongs to the enclosing
function, so the closure moves it as the lines would have. A run's
length, where an enclosing extent needs it, is the same: the plain
measurement wrapped in a `handing` that returns it.

Making it agree took 26.808 first: the Lua extent function counted a
`parameter`'s width as bytes, which put every element after the first
two bytes late.

With this, 0068 step 6 is complete for every shape steps 2 to 4 build:
a single member, a run of any shape, and an arm.
