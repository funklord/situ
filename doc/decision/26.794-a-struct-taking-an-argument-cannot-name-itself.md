# 26.794: A struct that takes an argument cannot name itself yet

Status: recorded -- fixed
Date: 2026-11-01
Source: designing element arguments (0068)

    struct node [depth = 4] { parameter u8 b; u8 n; node kids[n]; }

0050 refuses a struct that takes an argument as a member of another,
because the parent's accessor builds the child's view and has no argument
to pass. `check_parameter_nesting` let a struct naming itself through, with
no reason recorded. The schema above was accepted, and the C header declared
`situ_node_required` both with the argument and without it, then called it
with too few. That is a header which does not compile, for a schema `situc`
reported as fine.

A struct naming itself is built by its own accessor exactly as any member
is, so the refusal covers it. Supplying the child its argument is what 0068
designs.

`test_codegen_python.py::test_a_struct_that_takes_an_argument_cannot_name_itself_yet`
fails with `situc/wellformed.py` reverted. No corpus schema has the shape.
