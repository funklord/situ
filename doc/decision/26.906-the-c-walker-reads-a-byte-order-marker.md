# 26.906: The C walker reads a byte-order marker

Status: recorded
Date: 2026-11-06
Source: the assumption left by 26.901, that TIFF could stay `cannot-say`

`situ_walk_marker` has answered which order a marker states since 26.597, and
nothing in the walker asked it: a governed member's multi-byte read declined,
so every TIFF was `cannot-say` where the Python walker and all four backends
answer. `read_deep` asks it now and writes the answer into the row it reads, to
`walk.marker_order`'s rule, including that no marker in scope is no answer.

TIFF leaves `DECLINED`, so its vectors and its near misses are compared.
`endian native` stays declined, which is 26.356's question and not this one. A
`tlv` number under a marker stays declined too (26.864): no schema has one.
