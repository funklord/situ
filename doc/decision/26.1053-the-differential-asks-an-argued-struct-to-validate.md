# 26.1053: the differential asks an argued struct to validate

Status: recorded
Date: 2026-11-17
Source: 26.1051, a regression the differential could not see

**The four-way differential compared no struct that takes a `parameter`.**
Its input is one hex string, and an argument is not in it (0050), so
`skipped_of` held such structs out and every driver printed a note
saying so. Rust's check of a parameter's own bound against the next
member's byte, and Python's against a property that does not exist
(26.1051), lived in exactly that hole.

## The rule

A struct that takes arguments is still held out of the probes, and is
now acquired with ARGUED values and asked to `validate`, in all four:
each argument is its `[min]` where it states one, else 1, held under its
`[max]`. The note names the values -- "validate only, with n = 1" --
since they are invented, and a verdict over invented arguments is still
one the four readers must agree on.

## Measured

Over the seven corpus schemas where the harness acquires an argued
struct (dnsname, flac, mqtt, pcap, tiff, wasm, edges -- 1120 argued blocks)
and 26.805's fixture (80), 40 random draws each: every argued block
agrees. `keystore` and `std/image` declare parameters and give the
harness no argued struct to acquire, so they asked none. Over PCI VPD's schema the same sweep
found 26.1052 in a probe beside it.
