# 26.972: the doc draws no parameter

Status: recorded
Date: 2026-11-12
Source: `test_doc`'s ruler widths over `example/tiff` (26.969)

`situc doc` drew a `parameter` as a field. A parameter is the caller's
and occupies no bytes; its placement sits at the offset of the member
after it, and the diagram drew a cell of its type's width there. A pcap
record showed a four-byte `order` above `ts_sec` -- a record whose first
four bytes are a byte order, which it has not got -- at a width the
ruler test accepts, so nothing failed. A TIFF directory entry's
sixteen-bit `order` beside `tag` and `type` made a 48-bit row, which the
test refused. The table listed the parameter at offset 0 with its type's
size.

The diagram leaves parameters out, and the table lists one with no
offset and `argument` for its size. `test_a_parameter_is_not_drawn_as_
bytes` fails with the change reverted.
