# 26.911: a `known` name is a method on the view

Status: recorded
Date: 2026-11-06
Source: found while measuring what 26.909 left open

**`tlv items (known = { 1 : { name = mtu, ... } })` beside `u8 mtu;` was four
answers to one schema.** Rust and Python give each `known` name an accessor on
the struct's view; C and C++ give none. Measured over eight colliding names:

    C, C++  accepted, the name unused
    Rust    E0592 for `mtu`, `items_find`, `items_count`, `validate`
    Python  refused `mtu` and `items`; raised the AssertionError kept for
            its own defects on `items_find`, `items_count`, `validate`;
            quietly replaced `View.as_bytes` and `View.bytes`

The assertion says no member is responsible, and it is right: the `known`
entry is, and `_collision` looks only at members.

**Refused at the schema line, as 26.706 refused `arg_n`.** A `known` name is
the schema's own and the wire carries the tag, so a rename changes no message.
Two regions of one struct share a view and so share these names, including two
arms of a variant.

**Rejected: prefixing the accessor with the region.** It would remove the class
and rename every accessor existing consumers call, `uri_host` among them.
**Rejected: a guard in each backend.** That is 0062's answer for one backend,
and leaves C and C++ accepting what the other two refuse.

**The list is held to the generated code.** 0062 warns that a list is a second
copy of the emitter and goes short by one. `VIEW_SURFACE` is such a list, so
`test_a_known_name_is_refused_once.py` harvests every name Rust and Python bind
for a shape with a run, an arm and a region, plus `View`'s own, and requires
each to be refused. It found two omissions on first running: `SIZE_MIN`, and
the `<variant>_<arm>` spelling of an arm's accessors. It covers that shape, so
a name only some other shape generates is not proved.

**A plain member is not changed.** `u8 validate;` still fails in C++ and Rust
and `u8 new;` in Rust. 0013 leaves that to the compiler and 0062 chose refusal
over mangling, and the compilers do refuse. A protocol field really called
`validate`, `new` or `required` has to be renamed in the schema.
