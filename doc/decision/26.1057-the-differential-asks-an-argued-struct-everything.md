# 26.1057: the differential asks an argued struct everything

Status: recorded
Date: 2026-11-17
Source: 26.1053, which compared a struct that takes arguments by its
`validate` alone; the holder's word, 2026-11-17, to finish it

**26.1053 left the probes out, and the reason was C.** C++, Rust and
Python hold a struct's arguments on the view, so a driver hands them once,
to the constructor. C passes them per call -- and only to the accessors
whose bodies read one (`_argument_tail_in`) -- so a driver could not say
which of its calls take the tail. 26.805's test had measured what asking
anyway did: `asks` probed the parameter itself, which no backend has an
accessor for, and gcc refused five calls for too few arguments.

## The rule

`asks` skips a `parameter`. An argued struct is acquired with its argued
values (26.1053) and asked every probe an ordinary struct is, in all four.
C's calls are handed the values where the header the C backend wrote
says a function takes them: its prototypes ending in `arg_*` parameters,
read off the generated text rather than decided again in the driver, so
the driver cannot disagree with the backend about which calls take the
tail.

## Measured

Over the seven corpus schemas with an argued struct and two fixtures, 40
random draws each, every argued section agrees in all four; `edges`
alone asks 188 probe lines across its 12 argued sections. With C handed
each argument plus one, `edges` disagrees on the first draw.
