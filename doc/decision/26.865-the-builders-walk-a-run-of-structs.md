# 26.865: The three builders walk a run of structs

Status: recorded -- 184 builders over 30 schemas, 76 of them an arm. Tagged
records, delimited runs and varints are the largest slices left
Date: 2026-11-05
Source: 26.862's measure, where `repeat` was the largest slice

A run of inner structs is handed over as one span of bytes, as in C, and all
four shapes reduce to one walk: a fixed count, a count field, the rest of the
frame, and a delimiter. Each element's own `required` says where it ends, and
the view validates it. The reasons are C's `_walk`, which each language now
repeats: a zero-byte element would never advance the loop, a delimiter breaks
the run only at an element boundary, and an element the buffer ended is taken
on approval, so its failure means the bytes are not whole elements.

- **A count field** is what the walk finds, so the walk happens at that field
  and not again at the run.
- **A `while` run** ends where a predicate stops holding. That is the reader's
  to evaluate, so its count is held against the walk's rather than reproduced.
  A struct with two is declined, there being one walked count.
- A size field measuring a delimited run, a count field written in bits and a
  run with arguments are declined.

**The element's `validate` has no independent witness.** Removing it from
Python's walk changes nothing, because the whole-message `validate` has
reached a run's elements since the element validators landed. C's comment
says it does not, and that is out of date. The call stays: it is what names
the element, and it refuses before anything is copied.

**Every local in Python's builders is now `situ_`-prefixed**, as C's and C++'s
are. A member called `tail` overwrote the walk's flag, and `out`, `need` and
`count` were the same collision waiting.

`_reads_back` allows `required` to ask for more only where a run has nothing
but the frame to end it: `required` frames a stream, and netlink's attributes
end where the message does.

## Tests

`test_a_nested_member_is_one_whole_message.py` holds all four to each shape:
the count written, a cut element, one its rule refuses, too many and too few
for a fixed count, a delimiter at a boundary, a `while` run with bytes past
its end, and a run of zero-byte elements. Removing the count check and the
`while` check in Rust and the boundary check in C++ each fails it. In the
differential 143 of 184 units build, and the other 41 are compared on refusing.
