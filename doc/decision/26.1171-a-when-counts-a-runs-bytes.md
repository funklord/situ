# 26.1171: a `when` counts a run's bytes

Status: recorded; built in the four backends, both walkers and the
dissector (a delimited or fixed run; a sized one it declines)
Date: 2026-11-24
Source: fuzznet, inbox 20261124T1616Z -- its remote permit's host key and
its group list's names, both still hand-written for want of it.

## The rule

In a `when`, `count(s.key)` of a run of bytes -- a `u8` or `i8` run that
is counted, sized or ended by a terminator, never a text number -- is its
bytes with no terminator among them.

## Why `size` could not say it

`size` is the member's extent, and a terminator that is there is part of
the member while one that is not is not. So for `u8 key[] until " " | end
max 65`, 64 digits then a space and 65 digits at the end both measure 65,
and a name of one character at the end measures like an empty name ended
by a space. No `size` rule separates them; fuzznet tried both
(`size != 64` refuses a good permit, `size < 64 || size > 65` takes a bad
one).

## Options weighed

- **`count`**, taken. It already means a run's elements (section 10,
  26.1170's `count(s.rules)`), and a run of bytes' elements are its bytes;
  the terminator is no element. No new keyword, so no schema loses a name.
- **A new call, `length(key)`.** A second word for "how many elements",
  and a keyword that would capture any member named `length` in a clause.
- **A fixed `u8 key[64]` followed by `" " | end`.** Moves the ambiguity
  one member along, as fuzznet found.

## How it is read

Every backend already has the run's content length -- C's `_len`, the
span's size in C++, Rust and Python -- so `run_equalities` lifts the call
as `RunLength` and each renderer reads that. Both walkers answer the
image's `COUNT` from the run's scan, which already separated content from
terminator. The dissector reads the `<name>_len` its own scan of a
delimited member declares, behind `<name>_len ~= nil` so a member it did
not reach leaves the rule silent rather than failing to run, and a fixed
run's count as the constant; a sized run it still declines, its `_len`
being the footprint where `[size = N]` pins one. Real tshark agreed on
the permit's 64 and 65 digits.

Written beside it: `unique` over a delimited key compares the content in
both walkers, as the backends already did -- the C walker compared the
terminator too, so "a a" was two names, and the Python walker declined.
