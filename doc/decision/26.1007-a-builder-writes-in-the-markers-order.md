# 26.1007: a builder writes in the marker's order

Status: recorded
Date: 2026-11-13
Source: the goal gap -- builder refusals over the example schemas

**TIFF's header and pcap's could not be built**: "is a marker, whose value
the schema pins: it needs no caller and is not written yet". The premise was
wrong as well as the gap -- an endian marker is not one pinned value but a
choice between declared literals, and the choice is the caller's: it says
which byte order every field in its scope is written in.

**Now a role of its own, `MARKER`, in all four builders.** The caller hands
over the marker's literal -- the value its getter reads, so pcap's
nanosecond magics are as writable as the first pair -- refused unless the
schema declares it. It is written as the table spells it, and sets the
order every scalar in its scope is stored in at run time. A pinned field
there -- TIFF's `magic [must_eq = 42]` -- has no fixed bytes, so it is
written from the schema's value in that order rather than asked for.

**And a fault the work found.** A struct whose order is handed down as an
ARGUMENT -- TIFF's `ifd_entry`, which takes the header's (26.961) -- had a C
builder, and its fields were written big-endian whatever the argument said:
`_store` read the static order of a member that has none. A little-endian
TIFF's directory entries came out big-endian, and nothing could tell,
because validation does not read byte order and the other three builders
do not serve an argued struct, so there was nothing to disagree with. C
reads the argument now; the other three still do not build such a struct.

**Measured against TIFF 6.0 section 2**: `II*\0` and a little-endian offset,
`MM\0*` and a big-endian one, in Python and C, an undeclared marker refused;
an ImageWidth entry built little-endian from the order argument, which fails
with the change reverted. `test_the_four_builders_agree` reaches
`tiff_header`, handing over the little-endian literal -- the one that tells a
writer ignoring the marker from one honouring it. pcap's header remains
unbuilt for another reason: its packet run takes an argument.
